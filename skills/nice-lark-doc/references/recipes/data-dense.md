# 数据密集 Recipe

表格主导、对比清晰、数据说话。适合需要多维度对比、用数据支撑结论的报告。

## 设计系统

### 标题体例
- 使用分析维度作为标题：「XX 对比」「XX 趋势」「XX 分布」
- h1 只用于文档标题，正文从 h2 开始
- 2-3 层标题（h2 + h3 + h4）
- 标题直接点明分析维度

### 段落规则
- 段落简短，每段 2-3 句
- **连续纯文本段落不超过 2 段**，第 3 段前必须插入表格或画板
- 段落仅用于引出表格或总结表格结论
- 避免纯叙述性段落
- 数据结论用加粗突出

### 视觉打断规则
- 每个 h2 章节必须有至少 1 个表格 + 1 个 callout（数据结论）
- 表格是文档主体，文字是表格的引子和结论
- 多维度分析时，用画板展示趋势/分布/关系
- 关键数据发现用 callout 高亮
- 视觉元素占比应 ≥ 50%

### 表格使用
- **极高频使用，表格是文档主体**
- 每个 h2 章节至少 1-2 个表格
- 允许 4-5 列
- 表头 light-gray 背景
- 关键数据行可用浅色高亮
- 对比类内容必须用表格，不用段落描述

### 画板策略
- 适度使用，辅助表格，展示数据背后的规律和洞察
- 每个 h3 子维度建议 1 个画板
- **路径选择**：
  - 趋势分析 → SVG（简化折线/柱状 + 关键标注 + 色彩区分维度）
  - 分布/占比 → Mermaid（pie）或 SVG（气泡/矩阵图）
  - 因果归因 → SVG（鱼骨图 / 因果链）
  - 指标对比 → SVG（雷达图 / 对称结构）

### 高亮块 (callout)
- 用于核心数据发现（green）和异常值（red）
- 每个 h2 至少 1 个（数据结论）
- callout 内放 1-2 句关键数据结论
- 数据异常 / 风险提示用 red callout

### Checkbox
- 用于后续待分析的问题
- 用于数据验证待办

### 颜色语义
- 配色模式：**单色渐变**（色彩区分数据维度）
- 主色调：品牌蓝 #0050E0 家族，不同色阶区分维度
- 正向/增长/达标：绿 #16A34A
- 负向/下降/未达标：红 #DC2626
- 中性/基准：品牌蓝 #0050E0
- 待确认数据：橙 #CA8A04
- 详见 `references/color-palette.md`

### 字号参考
- h2: 18pt
- h3: 14pt
- h4: 12pt
- 正文: 11pt（略小，容纳更多数据）
- 行间距: 标准

### 可视化转译指南
以下内容应转为视觉元素，不用纯段落：
- 多维度对比 → 表格（必须）
- 趋势变化 → 表格 + 飞书画板（趋势示意）
- 占比/分布 → 表格 + 飞书画板（关系图）
- 数据结论 → callout（green/red）
- 异常值 / 风险 → callout（red）
- 指标定义 → 表格
- 数据源说明 → 表格

### 整体节奏
```
数据概览（摘要表格 + 关键发现 callout）
  ↓
维度 1 分析（表格 → 1 句结论 → 趋势画板）
  ↓
维度 2 分析（表格 → 1 句结论 → 对比画板）
  ↓
...（重复 3-5 个维度）
  ↓
综合结论（callout 汇总 + 后续行动 checkbox）
```
