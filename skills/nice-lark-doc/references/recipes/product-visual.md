# 产品叙事 Recipe

视觉化表达为主，用户故事驱动，画板丰富。适合需要跨团队沟通、让非技术人员快速理解的产品内容。

## 设计系统

### 标题体例
- 使用场景化标题：「当用户遇到 XX 时」「我们如何解决 XX」
- h1 只用于文档标题，正文从 h2 开始
- 2-3 层标题（h2 + h3 + h4）
- 标题带情感色彩，不用纯技术术语

### 段落规则
- 段落简短，每段 2-4 句
- **连续纯文本段落不超过 2 段**，第 3 段前必须插入视觉元素
- 使用「用户视角」叙述：「小明在使用 XX 时发现...」
- 适当使用 emoji 增加亲和力（每节 1-2 个）

### 视觉打断规则
- 每个 h2 章节必须有至少 1 个画板 + 1 个 callout
- 每 1-2 段叙述后，用以下方式打断：
  - 用户旅程 / 使用场景 → 飞书画板
  - 痛点 / 亮点 → callout（red/green）
  - 功能对比 → 表格
  - 界面示意 → 飞书画板（线框图）
- 产品文档的视觉元素占比应 ≥ 40%

### 表格使用
- 中高频使用
- 用于功能对比、用户画像、优先级排序、竞品对比
- 3-4 列
- 表头可用浅色背景

### 画板策略
- 首选飞书画板，**每个 h2 章节至少 1-2 个画板**
- 产品文档的视觉元素占比应 ≥ 40%，画板是主力
- 用户故事场景**必须**配画板
- **路径选择**（产品场景几乎全部走 SVG）：
  - 用户旅程图 → SVG（时间轴 + 情感曲线 + 触点图标）
  - 功能流程图 → SVG（活泼配色，圆角卡片，正交连线）
  - 界面线框图 → SVG（模拟 UI 布局，灰阶 + 品牌色点缀）
  - 角色关系图 → SVG（人物图标 + 关系连线）
  - 竞品对比 → SVG（对称/天平结构）
  - 数据指标趋势 → SVG（简化折线/柱状 + 标注）
- 画板风格活泼，可使用多色、渐变、阴影，充分发挥设计创造力

### 高亮块 (callout)
- 每个 h2 章节 1-2 个
- 用于用户痛点（red）、解决方案亮点（green）、待验证假设（yellow）、背景信息（blue）
- 配合 emoji 使用

### Checkbox
- 用于待验证的用户假设
- 用于下一步需要确认的问题

### 颜色语义
- 配色模式：**双色对比** 或 **多层分级**（最活泼）
- 主色调：品牌蓝 #0050E0 家族 + 暖色点缀
- 用户痛点：红 #DC2626（小面积）
- 解决方案/价值：绿 #16A34A（小面积）
- 待验证/待确认：橙 #CA8A04（小面积）
- 信息/背景：浅蓝 #93C5FD / 淡蓝 #BFDBFE
- 可大胆使用渐变和阴影
- 详见 `references/color-palette.md`

### 字号参考
- h2: 20pt
- h3: 16pt
- h4: 14pt
- 正文: 13pt
- 行间距: 略宽松

### 可视化转译指南
以下内容应转为视觉元素，不用纯段落：
- 用户使用流程 → 飞书画板（用户旅程图）
- 角色与权限关系 → 飞书画板（角色关系图）
- 功能列表 / 优先级 → 表格
- 竞品对比 → 表格
- 用户痛点 / 爽点 → callout
- 界面原型 → 飞书画板（线框图）
- 数据指标 → 表格 + 趋势画板

### 整体节奏
```
用户故事引入（1 段 + 场景画板）
  ↓
痛点分析（画板 + callout + 数据表格）
  ↓
解决方案（流程图 + 功能对比表 + 线框画板）
  ↓
用户验证计划（checkbox 清单 + 验证流程画板）
```
