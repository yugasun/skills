# 行动导向 Recipe

紧凑、可执行，checkbox 和待办为主。适合需要快速产出行动项、追踪进度的工作文档。

## 设计系统

### 标题体例
- 使用动作动词开头：「确定 XX」「完成 XX」「跟进 XX」
- h1 只用于文档标题，正文从 h2 开始
- 最多 2 层标题（h2 + h3）
- 标题即行动项分类

### 段落规则
- 极少段落，每段 1-2 句
- **连续纯文本段落不超过 2 段**
- 段落仅用于必要的背景说明
- 主体内容用 checkbox、有序列表和表格
- 不使用叙述性长文

### 视觉打断规则
- 每个 h2 章节必须包含至少 1 个表格或 checkbox 清单
- 背景说明后立即跟行动项（checkbox 或表格）
- 用 callout 标记关键决策和阻塞项
- 流程超过 3 步时，用画板可视化流程

### 表格使用
- 高频使用
- 用于：人员分工（人 + 任务 + 截止日）、优先级排序、进度跟踪
- 3-4 列
- 表头 light-gray 背景

### 画板策略
- 适度使用，风格简洁，重点突出
- **路径选择**：
  - 审批流程 / 决策树 → SVG（简洁节点 + 分支标注）
  - 操作步骤超过 5 步 → SVG（编号步骤 + 箭头连线）
  - 项目排期 → Mermaid（gantt）
  - 里程碑 → SVG（时间轴）

### 高亮块 (callout)
- 用于关键决策（blue）和阻塞项（red）
- 每个 h2 最多 1-2 个
- 用于标记会议关键结论

### Checkbox
- **核心元素，大量使用**
- 每个行动项都是 checkbox
- checkbox 后跟 @人 + 截止日期
- 格式：[ ] 任务描述 @负责人 YYYY-MM-DD

### 颜色语义
- 配色模式：**单色渐变**（简洁）
- 主色调：品牌蓝 #0050E0 + 中性色
- 已完成：绿 #16A34A（strikethrough）
- 进行中：品牌蓝 #0050E0
- 阻塞/风险：红 #DC2626（小面积）
- 待开始：蓝灰 #64748B
- 详见 `references/color-palette.md`

### 字号参考
- h2: 16pt
- h3: 13pt
- 正文: 12pt
- 行间距: 紧凑

### 可视化转译指南
以下内容应转为视觉元素，不用纯段落：
- 行动项清单 → checkbox 列表
- 人员分工 → 表格（人 + 任务 + 截止日）
- 决策记录 → callout（blue）
- 阻塞项 / 风险 → callout（red）
- 审批流程 / 操作步骤 → 飞书画板（流程图）
- 进度状态 → 表格（任务 + 状态 + 负责人）

### 整体节奏
```
会议/任务摘要（1-2 句）
  ↓
决策记录（callout 高亮）
  ↓
行动项清单（checkbox 分组，按负责人或优先级）
  ↓
进度跟踪表（表格）
  ↓
下次跟进（日期 + checkbox）
```
