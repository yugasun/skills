# 演示风格 Recipe

大留白、视觉冲击、一屏一个核心观点。适合需要给外部受众留下深刻印象的展示型文档。

## 设计系统

### 标题体例
- 大标题 + 简短副标题
- h1 用于文档标题，h2 作为「页面标题」（每页一个核心观点）
- 最多 2 层（h2 + h3）
- 标题精炼有力，像 PPT 标题

### 段落规则
- 极少段落，每段 1-2 句
- **连续纯文本段落不超过 1 段**，每段后必须跟视觉元素
- 大量留白，不密集排列
- 核心观点用大字号 + 加粗突出
- 不用长文叙述，用关键词 + 画板表达

### 视觉打断规则
- 每个 h2 章节必须有 1 个大画板（占据视觉主体）
- 文字和画板交替出现，节奏感强
- 画板 > 文字，视觉元素占比应 ≥ 60%
- 每屏信息量控制在 1 个核心观点 + 1 个视觉元素

### 表格使用
- 极少使用
- 如必须，仅 2 列（指标 + 值）
- 不使用复杂表格
- 数据用画板展示优于表格

### 画板策略
- 首选飞书画板，**每个 h2 章节必须有 1 个大画板**（占据视觉主体）
- 画板是信息传达的**主要载体**，文字只是引子
- **路径选择**（演示场景几乎全部走 SVG）：
  - 核心观点图 → SVG（大气构图，品牌色 + 1 辅助色）
  - 产品架构 → SVG（简洁分层，大留白）
  - 流程/路径 → SVG（流畅曲线，视觉引导线）
  - 对比优势 → SVG（对称结构，视觉冲击力）
  - 数据亮点 → SVG（简化图表 + 大字号标注）
- 画板风格大气、简洁、高级感
- 颜色克制，主色 1-2 种，大胆使用留白和视觉层次

### 高亮块 (callout)
- 用于核心数据亮点（green）或关键信息（blue）
- 每个 h2 最多 1 个
- 字号略大
- 用于一句话总结 / CTA

### Checkbox
- 不使用

### 颜色语义
- 配色模式：**单色渐变**（大气高级感）
- 主色调：品牌蓝 #0050E0 + 1 个辅助色
- 不使用多色混搭（最多 2 个色相）
- 背景保持白色或冰蓝 #EFF6FF
- 大色块、强对比、留白充分
- 详见 `references/color-palette.md`

### 字号参考
- h2: 24pt
- h3: 18pt
- 正文: 14pt（比常规大）
- 行间距: 宽松

### 可视化转译指南
以下内容应转为视觉元素，不用纯段落：
- 核心观点 → 大字号加粗 + 画板
- 流程/路径 → 飞书画板（流程图）
- 数据亮点 → callout（green）
- 产品架构 → 飞书画板（架构图）
- 对比优势 → 飞书画板（对比图）或极简表格
- CTA → callout（blue）

### 整体节奏
```
封面（大标题 + 副标题 + 品牌画板）
  ↓
核心观点 1（1 句 + 大画板）
  ↓
核心观点 2（1 句 + 大画板）
  ↓
...（重复 3-5 个核心观点）
  ↓
结语（1 句总结 + CTA callout）
```
