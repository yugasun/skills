# 素雅编辑 Recipe

安静、克制的长文风格。段落优先，但仍需保持视觉节奏。适合需要读者沉浸阅读的深度内容。

## 设计系统

### 标题体例
- 不使用数字编号，用自然语言标题
- h1 只用于文档标题，正文从 h2 开始
- 最多 2 层标题（h2 + h3）
- 标题简短有力，像杂志小标题

### 段落规则
- 段落是主要表达单元，每段 4-8 句
- **连续纯文本段落不超过 3 段**，第 4 段前必须插入视觉元素
- 避免使用加粗过多，仅在核心概念首次出现时加粗一次
- 不使用 emoji

### 视觉打断规则
- 每 3 段纯文本后，插入以下任一视觉元素：
  - 一个精炼的总结性 callout（blue，1-2 句核心洞见）
  - 一个小型对比表格（2-3 列）
  - 一个概念关系画板
- 长章节（超过 8 段）必须有画板或表格打断

### 表格使用
- 适度使用，每 2-3 个 h2 章节至少 1 个表格
- 表格简洁，2-3 列，不超过 5 行
- 不使用彩色表头

### 画板策略
- 首选飞书画板，风格素雅克制
- 每个 h2 章节建议 1 个画板
- 全文至少 2-3 个画板
- 颜色克制（灰、蓝为主），不使用过多渐变和阴影
- **路径选择**：
  - 分类体系 / 层次关系 → Mermaid（思维导图）
  - 概念关系 / 因果链条 → SVG（简约风格，少量色彩）
  - 演进过程 → SVG（时间轴风格）

### 高亮块 (callout)
- 每个 h2 章节最多 1 个
- 用于核心洞见、关键转折、总结性观点
- 语义色：blue（说明）

### Checkbox
- 不使用

### 颜色语义
- 配色模式：**单色渐变**（最克制）
- 主色调：品牌蓝 #0050E0 + 浅蓝 #93C5FD + 蓝灰 #64748B
- 只用 2-3 个色阶，不用语义色（红/绿/黄）
- 背景色保持白色或冰蓝 #EFF6FF
- 详见 `references/color-palette.md`

### 字号参考
- h2: 18pt
- h3: 14pt
- 正文: 12pt
- 行间距: 标准

### 可视化转译指南
以下内容应转为视觉元素，不用纯段落：
- 两个以上概念的对比 → 表格
- 因果链条 / 演进过程 → 飞书画板（流程图）
- 核心洞见 / 转折结论 → callout
- 分类体系 / 层次关系 → 飞书画板（思维导图）

### 整体节奏
```
引言（2-3 段）
  ↓
主体章节（每节 2-3 段 → 表格/画板 → 1-2 段 → callout）
  ↓
结语（1-2 段，收束全文 + 总结 callout）
```
