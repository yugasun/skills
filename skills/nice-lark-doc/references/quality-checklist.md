# 文档质量自检清单

在 Phase 3 内容创作完成后、Phase 4 渲染之前，逐项自检。

## 结构检查

- [ ] 标题层级不超过 Recipe 规定的最大深度
- [ ] 标题编号格式与 Recipe 一致（数字编号 / 自然语言 / 场景化）
- [ ] h1 仅用于文档标题，正文从 h2 开始
- [ ] 同级标题不跳号（有 1.1 就必须有 1.2，不能直接到 2）

## 视觉密度检查（关键）

- [ ] **连续纯文本段落不超过 Recipe 规定上限**（素雅/技术=3，产品/数据/行动=2，演示=1）
- [ ] 视觉元素占比达到 Recipe 要求（素雅≥20%，技术≥30%，产品≥40%，数据≥50%，演示≥60%）
- [ ] **画板是视觉主力**：复杂概念（架构、流程、关系）优先用画板，而非纯段落或表格
- [ ] 每个 h2 章节至少有 1 个画板（除行动导向和数据密集可适度减少）
- [ ] 没有「文字墙」段落（连续 4+ 段纯文本无任何视觉打断）
- [ ] 视觉元素分布均匀，不扎堆在某一个章节
- [ ] 多个独立画板已规划为并行创建（SubAgent）


## 长文档降级规则

当 h2 章节数 ≥ 8 时，视觉元素硬性规则按章节类型分级执行：

| 章节类型 | 判定标准 | 画板要求 | 表格要求 | 示例 |
|---|---|---|---|---|
| **核心章节** | 承载方案/架构/流程/分析的主体内容 | ✅ 必须有 | ✅ 必须有 | 背景、方案设计、架构、实施计划 |
| **辅助章节** | 支持决策但不承载核心论证 | 画板**或**表格至少一个 | 画板**或**表格至少一个 | 讨论问题、下一步、FAQ |
| **元信息章节** | 纯引用/索引性质 | 不强制 | 不强制 | 参考来源、附录、术语表 |

**章节分类判定流程**：
1. 如果章节包含技术论证、系统设计、实施方案 → **核心章节**
2. 如果章节包含行动项、讨论点、待决策项 → **辅助章节**
3. 如果章节仅包含引用列表、术语定义、附录 → **元信息章节**

**降级不等于跳过**：辅助章节仍应追求视觉丰富度，只是在硬性规则上允许画板或表格二选一。

## 可视化转译检查

- [ ] **架构/流程/关系**已转为飞书画板（SVG），未用段落描述
- [ ] **时序/状态/分类**已转为飞书画板（Mermaid），未用段落描述
- [ ] 对比类内容已转为表格，未用段落描述
- [ ] 关键结论/约束已转为 callout，未淹没在正文中
- [ ] 行动项已转为 checkbox，未用纯文本列表
- [ ] 每个画板选择了正确的路径（Mermaid vs SVG）

## 段落检查

- [ ] 每段句数不超过 Recipe 规定的上限
- [ ] 没有孤立的单句段落（除非是标题引导或总结）
- [ ] 加粗使用克制，仅用于 Recipe 规定的场景

## 表格检查

- [ ] 表格列数不超过 Recipe 规定的上限
- [ ] 表格有表头
- [ ] 表头背景色与 Recipe 规定一致

## 画板检查（核心）

- [ ] 画板数量达到 Recipe 最低要求
- [ ] 每个画板已选择正确路径（Mermaid / SVG）
  - 思维导图/时序图/类图/饼图/甘特图 → Mermaid
  - 架构图/流程图/关系图/自定义图形 → SVG
- [ ] SVG 画板设计充分：打破矩形牢笼，色彩丰富，有设计感
- [ ] SVG 未使用不支持的特性（`<pattern>`/`<clipPath>`/`<mask>`/非阴影`<filter>`）
- [ ] 文字使用 `<text>` 标签（不是 `<path>`），保证可编辑
- [ ] 画板节点标签与正文术语一致
- [ ] **⚠️ 对比度安全**：每个 `<text>` 的 `fill` 与所在容器背景色对比度达标
  - 深色底（#4A6FA5 及更深）→ 白色文字 `#FFFFFF`
  - 浅色底（#60A0E0 及更浅）→ 深色文字 `#1E293B`
  - ❌ 浅色背景（#93C5FD, #BFDBFE, #DBEAFE）绝不用白色文字
- [ ] 画板颜色遵循 `color-palette.md` 蓝色系配色（品牌蓝 #0050E0 家族）
- [ ] 未使用纯黑（#000000），深色用 `#1E293B` 替代
- [ ] 暖色仅用于小面积点缀（< 10% 画板面积）
- [ ] 配色模式与画板复杂度匹配（单色渐变 / 双色对比 / 多层分级）
- [ ] 复杂画板已启动 SubAgent 并行创建（如有多个独立画板）
- [ ] 插入后已导出 PNG 预览并审查视觉效果
- [ ] 不满意的画板已修改并重新插入

## 高亮块 (callout) 检查

- [ ] callout 数量在 Recipe 规定范围内
- [ ] callout 语义色与用途匹配（info=blue, success=green, warning=red, pending=yellow）
- [ ] callout 不在同一章节内连续出现超过 2 个

## Checkbox 检查

- [ ] checkbox 仅用于 Recipe 规定的用途
- [ ] 不用于普通列表

## 整体节奏检查

- [ ] 文档开头有明确的引入（标题 + 摘要/引言）
- [ ] 文档结尾有收束（总结/下一步/CTA）
- [ ] 各章节密度均匀，没有某段突然变得很密或很松
- [ ] 视觉元素（表格、画板、callout）均匀分布，形成良好的阅读节奏
- [ ] 全文阅读体验流畅，文字和视觉交替出现

## 渲染预检

- [ ] 总 blocks 数量已计算，batch 分页已规划
- [ ] 所有 block_type 都在飞书 API 支持范围内
- [ ] 画板渲染降级链已确认（检查 lark-whiteboard / mmdc 可用性）
- [ ] 如覆盖现有文档，已确认用户同意覆盖
