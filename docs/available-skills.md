## Update Rule

在以下场景优先更新本文件：

1. 新增一个 skill。
2. 删除或归档一个 skill。
3. skill 的定位、适用场景或入口文件发生明显变化。

如果只是 skill 内部参考资料、脚本或实现细节变化，通常不需要同步修改 README。
